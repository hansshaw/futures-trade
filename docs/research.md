# 中国玉米期货监控与量化研究：资料核验和选型

核验日期：2026-10-27（北京时间）。本文是本项目的技术研究记录，不是交易建议。开源项目、订阅权益、交易参数会变化；接入时应固定版本并重新核对对应服务协议。文中的性能判断是架构评估，未经本项目硬件基准验证的数字不作为性能承诺。

## 1. 结论与边界

采用 **Electron + React 桌面界面、Go 常驻核心服务、后续独立 Python 研究与数据适配进程**。先形成“可追溯事件 → 结构化指标 → 可复现的单合约研究回测”闭环，再接入授权实时数据和模拟交易。交易网关、账户资金和确定性风控属于独立执行域；大模型用于信息提取与辅助解释，不直接产生可执行订单。

用户提供的 `c2701` 作为初始观察合约。本文没有取得带时间戳的授权实盘行情来核实它在运行时是否仍为主力。程序应显示主力判定所依据的行情日期、持仓量、成交量和规则；“主力连续”是数据商或系统定义的序列，不能把它当作一个可下单合约。

当前最重要的外部约束是数据质量和授权，而非计算语言：政府周报不能替代盘中企业调价，天气预报不能用事后实况倒填，到车量通常不是统一的公共交易所数据。本轮提供明确标识的演示数据、CSV/手动事件与观察、可配置 RSS/Atom、Open-Meteo 天气采集、事件分析和基础研究回测；它们不等于已经接通生产期货行情，也不证明策略有超额收益。天气采集器默认不自动运行，RSS/Atom 需要用户自行配置获授权源。

## 4. 事件质量与研究偏差

### 价格必须可比

原值和原单位不可丢弃。至少记录省市、企业/港口、报价对象、收购/出厂/到厂/平舱/成交价类型、干湿粮、水分、等级、容重、产年、税/运费、结算方式、有效时段与来源。例如元/斤到元/吨的单位换算为乘 2,000；干湿粮折价仍需明确扣水和烘干公式，不能仅做单位换算。只有同口径的历史值才计算调价幅度；缺口径的数据保留为待核验事件。

### 时间必须可追溯

同一条事件分别保存 `event_time`（发生/有效时间）、`published_at`（首次公开时间）、`received_at`（本系统实际收到时间）、`analyzed_at`（分析完成时间）。生产可交易信息的可用时刻不得早于系统实际接收和分析完成。历史档案没有可靠首次可用时间的，只能用于探索性研究；不能把今天补录的事件按几年前发生时间直接喂给回测。

同样，收盘后确认的主力排序只能用于随后时刻；当日最终日线的最高价/最低价/持仓量不能提前用于当日开仓。天气因子使用历史预报发布批次而非未来实况或事后再分析。新闻还存在删除、事后修改、转载和只保留重大事件的幸存者偏差。

### 大模型存在自己的前视风险

让今天的大模型“解读历史事件”可能利用训练中见过的后续市场走势；禁止在提示词中提供未来行情，也不能因此宣称完全消除了污染。应要求只从当前给出的原文抽取事实和证据，不让模型自由补写历史背景；记录模型、提示版本、原文哈希和输出。真正用于交易评估的事件因子，优先从现在开始前向留存并纸面观察。模型置信度不是经校准的概率。

### 回测不能掩盖市场限制

连续主力拼接跳空不等于可赚取收益；换月须旧合约平仓、新合约开仓，各计费用和滑点。日线无法推断盘中排队成交，价格触及涨跌停也不意味着能成交。结算价用于逐日盯市，最后价不能直接替代所有结算场景。单合约 MVP 只是验证数据/策略/资金账本接口：当前信号使用上一根收盘，撮合仍使用日末成交量作事后可成交性过滤，净值按收盘估值而未模拟结算价逐日结算。完整的事件因子、组合、换月、walk-forward、强平和盘口模型在后续阶段实现。

## 5. 数据、软件与实盘准入

数据采购清单应明确：账户/机器/并发限制、历史区间和修订、API 与批量下载、长期存储、备份、云服务器、衍生数据、再分发、外部 LLM 处理和账号停用后的保留权。订阅报价按签约时确认，不能把网页会员价当最终 API 成本。开源依赖固定版本，保存许可证与 NOTICE；仅参考思想与实际链接/分发第三方库是不同动作。

证监会公开说明，《期货市场程序化交易管理规定（试行）》自 2025-10-09 起实施，涉及交易前报告确认、系统接入测试和风险管理。后续实盘应依据届时有效规定和开户期货公司流程落实；MVP 不包含实盘下单。[证监会发布说明](https://www.csrc.gov.cn/csrc/c100028/c7564353/content.shtml)。

这些输入不阻止开发本地研究闭环，但决定生产接入和交易阶段的范围：目标桌面操作系统及架构；期货公司/授权行情账户；日线、分钟或 tick 的历史深度；现货、到车量和天气供应商权益；LLM 部署与数据出域要求；可接受延迟；模拟资金与后续真实风控上限。未获得前以配置项和清晰的缺失状态表达，不制造凭据或伪装真实连接。
