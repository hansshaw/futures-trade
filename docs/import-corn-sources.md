# 进口玉米参考指标与公开数据边界（v0.4）

核验时间：2026-10-28 22:19—22:20，北京时间。当前直接接入中储粮公开进口玉米竞价销售结果，每日检查最新公开场次，保存原始统计日期、发布事件、来源和首次本地可用时间。无需账号或付款。

## 已接入的实际数据

[中储粮公开交易结果列表](https://www.esinograin.com/resources/static/newindex/notice/gonggaolist.html?type=lyjyjg)及其网页使用的公开接口，支持按“交易结果 / 进口玉米”筛选。最新核验场次为 **2026-10-27 进口玉米（转基因）竞价销售**，[公告详情](https://www.esinograin.com/resources/getGgInfo?ggid=76bbbaf25f624b1ebd790b99c8612614&ubd=0215)的发布时间为 **10-27 10:00:13**，原文合计成交率 **41%**。

该结果没有披露计划吨数、成交吨数或成交均价。分公司行和合计行不是两笔可以相加的成交；程序只取原文合计成交率，不计算平均值，不用百分比反推吨数，也不填零。

**这是境内进口玉米存量的竞价销售，不是当天从海外新签采购、装船、到港、报关或全市场成交量。** 拍卖并非每天举行；“每日检查”与“每日都有交易”是不同概念。没有新公告时显示最近场次；结构有效但没有匹配结果时记录本次查询成功、暂无公告，并保留原有数据时间。网络失败、限流或解析异常则记录错误，保留上次成功数据。

## 采集、存储及界面

- 数据源 ID：`import_auction`；默认24小时自动检查，可手动测试/同步，最小自动间隔12小时。
- 每次只读取一个列表和最新一篇详情，最多2个请求；成功响应缓存60秒，避免连续测试和同步重复访问。HTTP 200也会检查业务状态和“当前访问人数较多”限流提示，不绕过访问控制。
- 观测类型：`import_auction_rate`，单位 `%`，有效范围0—100；`observed_at`的上海时区00:00仅表达场次日期精度，不是假定成交时刻。
- 事件保存网页发布时间；`available_at`由实际读取时刻产生。相同内容重复同步保留首次可用时间，修订另存，不能倒填为回测当时已知。
- 「市场总览」显示最近场次、成交率、未披露字段和口径；「数据与设置」显示同步健康状态与数据新鲜度；「当前盘面分析」将其作为独立证据引用；事件雷达可筛选进口拍卖事件。

核心实现位于 `backend/internal/importcorn/auction.go`。只访问固定官方HTTPS地址，不发送会员凭据，不跟随重定向；列表标题、日期、ID、合计行和比例不符合已知格式时拒绝猜测。后续网页增加吨数或价格时应扩展明确字段及测试，再加入界面；目前不能宣称这些字段已覆盖。

## 为什么没有完整的“每日进口成交量”

本轮没有核验到免费、完整、稳定的中国进口玉米逐日境外采购成交数据。不同指标必须分别建模：

| 指标 | 含义与频率 | 当前接入状态 |
| --- | --- | --- |
| 中储粮进口玉米拍卖 | 境内进口存量按场次交易，公告不定期 | 已接入公开合计成交率，日度检查 |
| 进口完税/到岸报价 | 由外盘、升贴水、海运、汇率、税费等构成的报价或估算成本 | 未接入；不是实际成交价。部分公开目录的具体数值受会员限制 |
| 海关进口量及金额 | 报关统计，常见公开汇总按月 | 本轮未接入；不能按天均摊伪造日度成交 |
| 海外出口销售、装船、采购招标 | 产地申报、装运或具体合同，各自有范围和发布周期 | 未接入；不能直接当作中国当天全部进口量 |

检索到粮信网的美国玉米进口完税价格目录，但实际表值需要会员；中华粮网的相关目录也不能证明匿名可取得持续、完整数值。会员购买、批量采集、历史下载与云端再分发权益应由供应商明确，不能把网页可见标题当作已获得数据。当前实现不需要这些账号；后续若选商业成本和采购数据，先确认字段与口径再采购，不假定具体价格。

## 研究时如何使用

41%仅描述该场次的原文成交率。没有拍卖底价、地区、质量、库龄、交割与运输条件、投放量和可比历史场次，不能单凭该比例判断全国供应强弱或给出方向性信号。若后续授权数据包含上述字段，应与同地区国产粮可比成本、港口库存、汇率与外盘一起分析，仍需保留发布时间和首次可得时间。

当前测试覆盖结构变化、真假合计、比例范围、未来日期、限流、无结果、缓存、取消及持久化幂等。真实只读探测取得1条观测、1个事件；没有使用账号、没有下单，也没有把本次晚间获得的结果回填为10月27日的可交易先验。
