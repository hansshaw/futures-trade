# 每日盘前、盘后AI分析（v0.5）

每日报告把真实行情、完成日线、企业公开收购表、山东晨间到车、产区天气预报、进口玉米库存拍卖、关联期现货和已公布事件冻结成一份证据快照，再调用配置的大模型整理。原始依据、统计/目标日期、首次获取时间、模型、提示词版本与输入指纹和输出一起保存。此功能不接订单，不自动修改策略或个人经验。

## 从界面使用

1. 打开「每日分析 → 报告设置」，填写服务基础地址、模型名称、API Key。协议采用兼容 `chat/completions` 的JSON模式，地址示例 `https://api.example.com/v1` 是占位符，不能直接使用；远程只允许HTTPS，本机模型可用HTTP。无需在终端配置环境变量也能使用报告模型。
2. 保存后点「测试已保存的模型连接」。测试发送一条明确的非市场示例，检查响应结构和原文引用；不保存报告或日记。模型服务可能对此请求计费。模型名称、账户权益与价格由服务商决定，本项目不附带付费模型账号。
3. 在「数据与设置」确认行情及需要的产业来源有有效记录。日报生成会检查已经启用且到期的来源，遵守原有采集间隔和失败退避；不会因生成报告就强制频繁刷新所有网站。缺失/陈旧数据会在报告里明确列出。
4. 点「生成盘前AI分析」或「生成盘后AI分析」。后台任务显示整理、模型生成、引用校验、保存等阶段；切换页面不会取消任务。任务失败不会用规则结果冒充AI，也不覆盖历史成功报告。
5. 报告中的「依据N」可直接定位该条原始资料及日期。可导出包含完整依据的JSON，或保存到复盘日记。开启自动保存后，AI报告会自动创建独立日记；打开已存复盘后可补充计划、实际执行和个人反思。

没有模型账号时可点「规则预览」检查数据与流程。规则预览不调用大模型、不会自动写日记，仍可手动保存。它不是对模型效果的验证。

## 时间与自动任务

默认北京时间08:30盘前、15:30盘后；设置允许盘前06:00—08:59、盘后15:15—19:00。自动开关和自动保存均默认开启，但必须有可用模型配置，才会发起模型任务。初次配置可继承 `LLM_BASE_URL/LLM_MODEL/LLM_API_KEY`；界面保存后，报告专用设置优先，事件分析和复盘智能体继续使用原有环境变量配置。

- 仅周一至周五并排除配置日期；**尚未接官方交易所节假日日历**。需要按休市公告添加排除日期，不把调休工作周末自动当成交易日。
- 程序/后端必须运行且电脑未休眠。默认盘前可在08:30—08:59启动或补执行；盘后可在15:30—16:29启动或补执行。通用宽限最多60分钟，盘前最晚09:00前启动。超过窗口记为错过，不在午间重新声称生成了开盘前可知的报告。若启动后的采集跨过09:00，报告按实际资料截止时刻标为当前补充研究，并附开盘后生成警告。
- 自动任务每研究日/时段只预留一次；预留与任务记录原子写入。退出、网络失败或模型返回无效结果后不会自动重复付费请求；重启把未完成任务标为中断，保留已消费的时段。
- 手动生成始终按现在实际可得资料进行。09:00之后生成盘前格式，或15:15之前生成盘后格式，均附明确时间警告，不能冒充历史时点报告。
- 日线只接受保守15:15门槛前已完成的日期；盘中行情与前一完成日的技术指标分列。夜盘自然日期、研究日期和交易所交易日没有被默认为同一概念。
- `CORNWATCH_REPORT_AUTO=false` 只暂停自动报告，手动仍可用；`CORNWATCH_AUTO_SYNC=false` 暂停来源自动采集，也让报告的计划内刷新复用本地已有数据。界面会显示报告调度是否被环境暂停。

自动时段不等于已经成功生成。查看「最近自动任务」和任务历史中的失败原因；需要时修改配置、同步数据后手动重新生成。

## 依据、模型与日记的边界

模型仅收到筛选后的市场证据白名单及限制说明，不收到API Key、账户状态、个人日记、截图或策略执行权限。天气允许未来目标日，但其预报版本必须在资料截止前已经获取；预报不能写成实况。公开通知在生效前属于公告事件。未注明单位的报价只保留原值，进口库存拍卖不等于新签采购量，无吨数/均价时不反推。

每个模型章节必须列出本次存在的证据ID，并给出该证据的精确原文片段；未知ID、引文不匹配、截断、工具调用、重复JSON键和超限响应均拒绝保存。模型不能自行指定生成时刻、模型身份或证据指纹。引用核验只能证明文字来自输入，**不能证明模型推断、因果关系或交易优势成立**；报告明确标注AI推断和风险。

报告永久保存生成时的完整输入快照，不因后来数据更新而改写。历史列表展示最近100份；原报告仍在库中。保存到日记使用报告ID实现幂等，即使跨数据库步骤中断，重试也不会创建重复日记或覆盖用户后来编辑。日记附报告ID、指纹和依据摘要，完整长文本保留在每日分析的原报告中。不会替你填写实际成交、盈亏或自动采纳交易经验。

设置中的密钥只写不回显，不写浏览器存储；更换服务基础地址而未提供新密钥时会清除旧密钥。配置存在本机权限为0600的数据库，**没有静态加密**；备份需妥善保管。更换配置只影响之后启动的任务，已开始的任务使用提交时的配置快照。

## 数据频率与请求限制

v0.6行情默认每500毫秒一次批量请求目标，行情推送只刷新本地行情接口，其他页面资料仍按低频本地读取；这不是来源的延迟承诺。日报与当前盘面分析共享5秒实际合约日线缓存和并发请求；快速行情成功缓存随配置缩短，失败仍至少冷却5秒。自动报告遵守各来源的原采集计划，详细默认值、Open-Meteo官方额度及未知限制见[请求频率说明](data-source-frequency.md)。

模型响应60秒超时，整个后台任务最多150秒；单实例只允许一个报告/模型测试任务同时进行。云端可以运行同一Go服务，但多实例调度、共享配额、TLS、用户隔离和跨机器凭据管理尚未实现。

## 验证与限制

后端测试使用真实协议的本地模拟模型，验证设置保密、版本冲突、任务持久化、时段幂等、异常输出、日记幂等、取消与重启。桌面验收可结合真实公开行情/日线与明确标注的模拟模型来检查完整操作链路；这不代表已用真实付费模型验证市场解读质量。需要填写你有权使用的服务配置并通过连接测试，才能在日常环境启用实际AI报告。
