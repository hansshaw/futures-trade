### 企业报价表的限制

原表未注明价格单位、水分、容重、霉变、干潮粮、含税/发票或扣量条件。采集器保存原始数值，`unit="未注明"`，`region="原页未标地区"`；不依靠数值大小、企业名称或其他来源推测单位和地点。例如 10 月 28 日表中德州福洋为 **2246（单位未注明）**，潍坊盛泰为 **2252（单位未注明）**；不能把这些数字自动标为元/吨。

每条 Note 明确禁止单位换算、直接计算基差、价格套利或交易信号使用。界面必须让单位与备注可见。若以后原表明确出现“单位：元/吨”，解析器才允许该单位；仍不会补造水分和发票条件。

只提取当前日期列，并验证标题日期、表格日期、前一期日期和每行涨跌算术。历史列不被当作一条当时已经可得的历史观测。按当前实际采集时刻入库，避免制造回测的先验历史。

### 山东到车的限制

原页写“山东深加工企业晨间到车辆”，但没有明确采样时刻、样本名单、企业数，也未说明是晨间新增到厂、门前剩余待卸还是另一种口径。采集器按原标签保存，车统一写为辆，实体显示“山东深加工晨间到车（原页口径未细分）”。

它不是全省全天累计，不能换成吨数，也不与来自其他机构的“剩余到车”“待卸车辆”直接拼成一个连续序列。页面标注博亚和讯并提示转载，但未指明原始调查机构；这一不确定性保留在每条记录中。

|---|---|---:|
| 门前农户 | 14% < 水分 ≤ 15%，三等及以上 | 2060 元/吨 |
| 门前农户 | 15% < 水分 ≤ 38% | 2030 元/吨 |

带票档要求 9% 税率发票，发票入账后 10 个工作日内付款；农户档为结算后 1 个工作日内付款。不得把“折标价”重新解释成任意水分实际过磅结算价。

生产从当前主列表动态发现链接，不固定抓上述历史 URL，也不声称扫描到了全站所有企业或所有修订。10 月 27 日通知是已核验的离线 fixture，但当它不再出现在主列表时不会被作为“最新数据”硬塞进生产批次。

## 时间与去重契约

| 字段 | 含义 |
|---|---|
| `observed_at` | 日报的统计日，上海时区 00:00 仅表示日期精度；明确企业通知则为其真实生效时刻 |
| Event `published_at` | 原网页实际发布日期与分钟时刻 |
| `available_at` | 本程序本次完成正文读取后的采集时刻；存储层遇同 ID 保留第一次入库的时间 |
| Event `ingested_at` | 本次采集时刻 |
| `source` / `source_url` | 发布平台、原文来源标签、实际详情页，始终保留转载关系 |
| `note` | 单位、水分、票据、样本口径与不足；不输出可交易性承诺 |

观测 ID 包含来源详情页、指标、企业/水分档、统计/生效时刻、数值、单位及口径，**不含抓取时刻**。重复采集保留首可用时间；正文修订成新数值或新口径会形成新观测，旧值不被回写。相同数值跨不同报告日期依然是不同日报观测。

公开日报可以被用于日后积累的事件回放与研究。当前采集到的旧日报不能因为网页标了旧统计日就回填成当时可用的交易信号，回测必须依据 `available_at`，并排除单位未注明记录的价格运算。

## 程序接口与边界

实现位于 `backend/internal/industrypublic/`：

```go
c := industrypublic.New()
prices, priceEvents, err := c.Prices(ctx)
arrivals, arrivalEvents, err := c.Arrivals(ctx)
```

两类由 datahub 独立调度并展示健康状态，ID 为 `boyar_prices`、`boyar_arrivals`；包内 `RecommendedInterval` 为2小时；应用调度更保守，默认12小时、最小6小时。单个源每次最多 **3 篇**相关公开报告（价格表与企业通知共同计数），每篇间隔 500 ms，单请求超时 20 秒，响应最大 2 MiB。不是盘中高频抓取器。

- 仅允许 `www.boyar.cn` 的 HTTPS 主列表和 `/article/<id>.html` 详情路径；不发送账号、Cookie 或 token。
- 仅主列表内发现文章；不抓热力排行，避免把热门旧文章当最新。
- 跳过原站标红的会员文章，登录/跨域/白名单外跳转直接失败。没有绕过验证码、会员限制或下载隐藏附件。
- 2026-10-28 核验的 [robots.txt](https://www.boyar.cn/robots.txt) 对一般代理没有禁止这些主列表/详情路径，但禁止带查询参数地址。故不访问带 `categoryid`、`page` 等查询参数的分页，也不依赖移动端 JavaScript 数据接口。该核验不是商业再分发授权。
- 页面结构、标题日期、单位、数值、来源或关键收购条件变化时返回明确错误，不凭大模型猜数值。某篇失败时该次源返回空批次和错误，避免“部分解析成功”掩盖遗漏；另一个源仍可独立成功。
- 返回文本属于不可信外部资料，后续交给 AI 时只能作为引用资料，不能当作程序指令。

## 验证结果

```sh
cd backend
go run ./internal/industrypublic/cmd/probe
```

- Prices：44 条观测 + 3 个事件，耗时约 2.27 秒；包含 10 月 28/27 日各 22 家企业原表数值，及尚未生效的吉林燃料乙醇公告。

`go test -race ./internal/industrypublic` 与 `go vet ./internal/industrypublic` 用于校验：未知单位、不确定到车口径、生效前后分离、数据与链接日期一致性、字段变更拒绝、分页/会员/热榜排除、请求上界、失败批次、重复导入首可用时间、认证跳转限制、大小限制及取消。
