# 授权行情与产业数据接入指南（v0.4）

公开快照、官方周报和天气不需要在本程序填写账号。交易级实时行情、更广企业覆盖及完整进口采购数据，需要来源方提供相应权益。本程序不会代为开户、购买服务或申请交易权限。

## 直接使用内置来源

启动应用后打开「数据与设置」。新浪公开快照、辽宁粮储周报、农业农村部饲料与畜产品周报、Open-Meteo 默认启用，分别按500毫秒目标、12小时、12小时、1小时请求。点「测试连接」只检查返回内容，点「立即同步」才保存数据。

新增博亚企业报价、山东晨间到车默认各12小时，中储粮进口玉米拍卖结果默认24小时检查。均不需要填写账号。拍卖不是每日必有，无公告不代表零成交，只有原文披露的合计成交率入库；目前吨数与均价缺失。

市场总览提供企业/地区/来源搜索、公开报价横向表和进口拍卖卡片。「生成当前分析」会额外读取一次新浪实际合约日线，自动剔除未完成交易日，保留来源、日期、输入指纹，且不写入回测日线库。分析可导出或带入复盘。

状态分为请求状态与数据时效。成功请求到上周发布的周报，不等于今天产生了新价格。天气的“预报采集时刻”不是预报目标日。关闭自动采集后仍可手动测试和同步。保存配置即生效，重启保留；界面内填写的令牌不会回显。

公开报价来自网页接口，无稳定性和延迟承诺。生产行情应使用账户授权的数据源。官方现货是特定统计口径的均价；已接入博亚和讯最新公开企业表和山东晨间到车，原页单位/样本不明时原样披露，不用于可套利基差；这些不是统一全市场实时调查。免费天气服务限非商业使用，商业用途需要采购或自部署；当前内置天气端点没有实现付费端点切换。

## TqSdk 只读行情桥接

需要 Python 3.9+、快期账号及相应行情权益。脚本固定监听本机127.0.0.1，只读DCE实际玉米、淀粉、生猪、豆粕合约。明确使用SDK本地TqSim对象，不配置真实券商账户，不调用订单或账户交易方法。它是可选的边缘适配器，主应用仍使用Go处理、持久化和提供API；这条秒级研究通道不是高频交易网关。

1. 在项目根目录创建独立环境并安装锁定的SDK版本：

   ```bash
   python3 -m venv .venv-tqsdk
   .venv-tqsdk/bin/pip install -r adapters/requirements-tqsdk.txt
   ```

   Windows PowerShell对应为 `py -m venv .venv-tqsdk`、`.venv-tqsdk\Scripts\python.exe -m pip install -r adapters\requirements-tqsdk.txt`。

2. 在运行桥接的终端设置 `TQ_USER`、`TQ_PASSWORD`、`CORNWATCH_BRIDGE_TOKEN`。前两个是上游账户；第三个是你自己生成的32至256位无空白ASCII随机访问令牌。不要将真实凭据提交到仓库或放入URL。`.env` 文件不会自动载入。

3. 启动（Windows用上述虚拟环境的python.exe）：

   ```bash
   .venv-tqsdk/bin/python adapters/tqsdk_bridge.py --port 8787
   ```

4. 在桌面的「授权行情 · TqSdk / JSON桥接」展开配置。端点填 `http://127.0.0.1:8787/quotes`，访问令牌填同一个 `CORNWATCH_BRIDGE_TOKEN`；勾选自动采集，按账户与服务权限设置间隔（支持0.5秒，即120次/分钟目标），保存后测试、同步。密码只在脚本环境中，桌面不需要快期密码。

5. 未登录、连接中断或SDK工作线程失去心跳时接口返回503。界面保留旧报价并显示失败及源时间；修复账户、网络或权限后重试。桥接停止后桌面不能继续获取授权报价。

当前真实公开源已实测；TqSdk桥接仅完成协议及模拟SDK测试，未使用付费账户登录。快期账户、实时与历史数据、并发数量和云部署权益以 [官方文档](https://doc.shinnytech.com/tqsdk/latest/quickstart.html) 和账户当前授权为准；不要把SDK开源或免费安装等同于全部数据免费。

## 自有或供应商JSON服务

配置的端点必须直接返回下述JSON，不能填写供应商首页或会员网页。远程仅HTTPS，本机HTTP可用；禁止URL中的账号、密码、查询参数和重定向。令牌通过 `Authorization: Bearer …` 发送。请求20秒超时、响应最大4MiB，未知字段和整批无效记录拒绝入库。

换服务的协议/主机/端口时，旧令牌不会被自动发给新服务，需重新提供。端点决定数据集身份；单纯换令牌不应造成产业数据重复。数据库文件权限保护配置，但没有静态加密，备份文件需要与密钥同等保护。

### 行情返回

```json
{
  "generated_at": "2026-10-28T15:16:00+08:00",
  "quotes": [{
    "symbol": "c2701", "product": "c", "exchange": "DCE", "name": "玉米",
    "trade_date": "2026-10-28",
    "observed_at": "2026-10-28T15:00:00+08:00",
    "received_at": "2026-10-28T15:00:01+08:00",
    "last": 2200, "previous_settlement": 2190,
    "open": 2195, "high": 2210, "low": 2185,
    "volume": 100000, "open_interest": 200000
  }]
}
```

**以上仅为协议示例，价格不是市场事实，不要将示例导入日常库。** 一次1至200条，无重复实际合约；不接受`c0`、主连或指数。玉米/淀粉/生猪只支持1、3、5、7、9、11月，豆粕额外支持8、12月。价格元/吨，量仓手；昨结算为正，涨跌幅在Go端重新计算为较昨结算。

`generated_at` 必填，是服务成功生成健康响应的时刻，距当前不超过2分钟、未来容差30秒；它不能用于替换原始报价时间。`received_at` 保留采集端实际接收时间，未提供时由本机补记；原始`observed_at`必须保留，即使休市没有变化。`trade_date` 如缺省只补源上海自然日期，不推断夜盘所属交易日。这些快照不会被当作历史K线导入。

### 产业返回

```json
{
  "generated_at": "2026-10-28T08:10:00+08:00",
  "observations": [{
    "kind": "truck_arrivals",
    "region": "山东某县",
    "entity": "已授权企业A · 晨间待卸车辆",
    "value": 36, "unit": "辆",
    "observed_at": "2026-10-28T08:00:00+08:00",
    "source": "企业授权调查",
    "source_url": "https://provider.example/report/20261028",
    "note": "08:00门外待卸车辆；仅企业A，不是全省累计到厂车辆"
  }]
}
```

**示例企业、数值和链接均为占位符。** 一次1至1000条；类型为`purchase_price`、`truck_arrivals`、`related_price`。主体、地区、来源、单位、口径必填；到车数为非负整数，单位“辆”（“车”会规范化为“辆”），卸粮吨数不能伪装成到车数。价格为正且保留原始元/吨或元/公斤等单位，说明水分、等级、含税/运费、交货条件或统计窗口。

产业`generated_at`可选，提供时同样校验响应时间；历史`observed_at`允许回补，首次本地可用时间由服务器赋值，不能用历史统计日冒充当时已知。等价重复记录不改首次可用时间；数值或口径修订另存版本。网页会员不等于API或批量使用权限：Mysteel、卓创等需另行核对数据字段、样本、历史长度、更新频率、采集/存储/再分发权利及报价。

## 主力确认与云部署

玉米主力按同一来源的实际合约量仓计算。首次确认需要两个不同的有效收盘观察日；当前15:15至20:55期间，只有源时刻15:00至15:20的当日收盘快照可计数。同日轮询不重复累计，过期日期不推进。已有主力只向远月切换，远月量仓均超过10%，两个有数据收盘日确认；缺数据不会虚构历史确认天数。切换记录含旧/新合约、依据日期和实际决策时刻，不产生换月订单。

一般交易时段只用于时效提示；没有完整交易所节假日日历，也不据自然日期推导夜盘交易日。若程序未在收盘观察窗口运行，需要等待后续有效样本。关联品种卡片取该批次最新日期中成交量领先的实际合约，不宣称完成四个品种统一主力确认。

后续云部署可保留Go API，桥接作为同机服务或经授权的HTTPS服务；需额外配置TLS、身份验证、备份及数据源云端使用权益。不要将本机Bearer桥接直接暴露公网。当前没有部署云服务，没有实现订单执行、逐笔低延迟链路或历史数据订阅。
